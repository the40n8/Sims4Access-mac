# SimSight keyboard on a Mac

The original mod's keyboard (CONTROLS.txt) works on the Mac with Mac keys.
The keys are taken only while The Sims 4 is the front app, so other apps,
macOS and VoiceOver keep their own shortcuts. Letters follow the letters
printed on your keyboard (AZERTY, QWERTZ...).

| Original (Windows) | Mac |
|---|---|
| Ctrl+Alt+key | **Control+Shift+key** (⌃⇧) |
| Alt+key (SimSight Plus) | **Option+Shift+key** (⌥⇧) |
| Alt+Shift+arrow (drawing cursor, 5 m) | **Option+Shift+Command+arrow** |
| Ctrl+Shift+N (needs) | **Control+Shift+N** |
| Arrows, Tab, Enter, Space, Backspace, Esc in menus and the scanner | the same keys |

Always on the Mac: **Option+Command+A** opens the SimSight menu,
**Option+Command+S** turns the speech on or off.

## On by default, and turning navigation on

The information keys (Control+Shift and Option+Shift) always work. Moving
through menus, dialogs and pickers with the arrows, Tab and Enter, and the
scanner, are off by default on the Mac (the sighted player uses the mouse):
turn **keyboard navigation** on in the SimSight settings menu
(Option+Command+A, settings menu), or type `simsight.keys on` in the cheat
console (Command+Shift+C). Bare keys are only taken while the mod owns
them (a menu or dialog is open, scanner mode is on, or the Build cursor is
active); otherwise the game gets them as usual.

## Control+Shift keys (the original's Ctrl+Alt)

| Key | Action |
|---|---|
| ⌃⇧ Up / Down | previous / next (scanner, or the open menu) |
| ⌃⇧ Left / Right | previous / next category |
| ⌃⇧ Page Up / Page Down | previous / next subcategory |
| ⌃⇧ Return | open the menu / activate |
| ⌃⇧ Space | scanner mode on or off |
| ⌃⇧ Delete | back / close |
| ⌃⇧ S / W / R | refresh the scanner / where am I / repeat |
| ⌃⇧ H | help (the accessibility menu) |
| ⌃⇧ C | day and time |
| ⌃⇧ P | waiting call or text |
| ⌃⇧ E / G | mood and moodlets / wants and fears |
| ⌃⇧ Q | action queue |
| ⌃⇧ L | diagnostic logging on or off |
| ⌃⇧ V | running events |
| ⌃⇧ M / K | milestones / character values |
| ⌃⇧ O / I | Buy catalog / search the catalog (Build mode) |
| ⌃⇧ 1 to 8 | control household Sim 1 to 8 |
| ⌃⇧ N | needs |
| ⌃⇧ B / T / F | Build placement / read-only grid / aim at a grid point |
| ⌃⇧ U / D / J | layer up / layer down / label the room |
| ⌃⇧ , / . | smaller / larger scanner range |
| ⌃⇧ [ / ] | rotate left / right |
| ⌃⇧ Z / Y / X | undo / redo / sell |

## Option+Shift keys (the original's Alt, SimSight Plus)

| Key | Action |
|---|---|
| ⌥⇧ A | Access Plus menu |
| ⌥⇧ Q | action queue |
| ⌥⇧ N | needs |
| ⌥⇧ L | last notifications |
| ⌥⇧ T | time and day |
| ⌥⇧ R | rooms |
| ⌥⇧ W | where am I |
| ⌥⇧ C | create and edit Sims |
| ⌥⇧ B | build helper |
| ⌥⇧ arrows (⌘ for 5 m) | drawing cursor |
| ⌥⇧ X / S / Z / D | drawing cursor: where / mark start / undo / draw |

Not on the Mac yet: the main menu and Create a Sim keys (before a save is
loaded), the build tools that move the real mouse, and numpad navigation.
